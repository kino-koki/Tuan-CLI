# 设计审美与界面质感

目标不是「花哨」，是「克制的高级感」。判断一个界面好不好，先看它是否安静。

## 排版（Typography）
- 字号分明确的层级（标题/副标题/正文/辅助），用比例（1.25–1.5 倍）而非随意数值。
- 行高 1.5–1.7，段落最大宽度约 60–75 字符，长文才可读。字重别超过 3 档。
- 中文用系统字体栈（PingFang / Microsoft YaHei），西文配 Inter；等宽用 JetBrains Mono。

## 间距（Spacing）
- 用 4 或 8 的倍数做间距尺度（4/8/12/16/24/32…），别随手写 13px、17px。
- 留白是设计的一部分。元素之间靠「关系」决定间距：相关近、无关远。

## 配色
- 先定中性灰阶（背景/文字/边框），再点缀一个主色。主色饱和度别拉满，高级感来自低饱和。
- 明度对比保证可读性；暗色界面背景用 #0f1115 一类的近黑而非纯黑。
- 语义色要克制：红=危险、绿=成功、黄=警告，且只在必要时出现。

## 质感细节
- 圆角统一（小元素 6–8px，卡片 12–16px）；阴影用「大模糊+低透明度」模拟自然光，别用硬黑边。
- 微交互要有反馈：hover/active/disabled 三态齐全；过渡 150–250ms 缓动，别用 linear 闪现。
- 边界用 1px 半透明描边代替重阴影，界面更轻。

## 自检
做完问自己：去掉所有颜色它还成立吗？信息层级还清楚吗？如果成立，就是好设计。
