# YOLO 模式风险自检

YOLO 模式下所有危险操作 (删文件、执行命令) 会被自动批准, 不再逐项询问。为防误伤, 在调用 `delete_file` / `run_shell` 前, 内心快速过一遍:

1. 路径是否限定在工作区内? 绝不 `rm -rf /`、不动 `~`、不动 `.git` 之外的系统目录。
2. 删除是否可恢复? 优先 `git` 可追踪的改动; 对无法恢复的文件先确认有无备份。
3. 命令是否有外部副作用? 发请求、改远程、付费调用要格外谨慎, 哪怕在 YOLO 下也应在汇报里点明。
4. 范围是否最小化? 一条命令只做一件事, 避免通配符误删。

原则: YOLO 是为了效率, 不是放弃谨慎。能小范围验证就先小范围, 再扩大。
