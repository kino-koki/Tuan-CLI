# 39. X (Twitter) — Everything App 极简黑

> **类型**：软件 | **领域**：社交平台 | **设计哲学**："Digital town square" 高密度信息流

| 规格总览 | 值 |
|---|---|
| 画布色 | `#000000` 暗色 / `#FFFFFF` 亮色 |
| 强调色 | `#1D9BF0` X蓝 |
| 字体策略 | 系统字体栈（SF / Segoe / Roboto） |
| 记忆点 | 全圆角胶囊 + 信息流高密度 |

## HTML 板块 · 官网与营销页

### 设计哲学

X 官网与产品高度合一：用"信息流即页面"的方式呈现，hero 常是巨型标语 + 登录/注册双胶囊按钮。设计语言刻意极简——黑或白单一画布、无彩色渐变、无装饰性插画，一切为了"让你快点进来刷"。暗色模式是默认美学，亮色模式等同反转。

### 色彩

暗色画布 `#000000`/`#0F1419`，亮色画布 `#FFFFFF`。主强调 X 蓝 `#1D9BF0`（链接、CTA、选中态、通知点），辅助文本灰 `#536471`（暗色下 `#71767B`）。品牌黑 `#0F1419` 用于亮色模式标题。**系统内禁止出现品牌红/黄/绿等彩色的任意填充**。

### 字体

无自定义字体——直接使用平台系统栈 `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`；数字展示常用等宽感（时间戳用小号 tabular）。标题用 23–44px ExtraBold，正文 15px 常规；间距以行高 1.2–1.5 紧凑收拢。

### 布局、间距、圆角与动效

桌面内容列 600px 居中、左右固定栏 350px；垂直 8px 基线网格；按钮 9999px 胶囊（高 40–52px），卡片与弹窗 16px；hover 用黑色叠加层（暗色下白色 8%）；动效 150–200ms ease-out，无夸张动画。社交页面的"点赞/转发/评论"行间距 12px。

## UI/UX 板块 · 产品界面

### 设计哲学

产品界面以"信息密度优先 + 颜色克制"为核心：时间线、侧栏、模态框都用中性色层叠出层级，唯一的彩色是交互蓝。暗色是主场——`#000000` 纯黑底让图片和视频成为页面主角，任何系统 UI 色都不与内容抢注意力。

### 色彩（组件与语义 Token）

语义：品牌蓝 `#1D9BF0` = 主行动/链接；危险用标准红 `#F4212E`（删除、封禁）；成功灰绿仅提示。层级底色：`#FFFFFF`（亮）/`#000000`（暗）→ 悬停叠加层 → 分割线 `#EFF3F4`（亮）/`#2F3336`（暗）→ 次级矩形卡片 `#F7F9F9`（亮）/`#16181C`（暗）。

### 字体

正文 15px/1.56；标题 20–23px ExtraBold；按钮 15px Bold；数字与时间用 tabular-nums。桌面端字号可比移动端 +2px。中文界面回落系统中文字体栈（PingFang SC / Microsoft YaHei）。

### 布局、间距、圆角与动效

网格：左栏 275px（导航）、主列 600px、右栏 350px；卡片内 padding 16px；列表项行高 ≥44px（移动端无障碍）；头像 32–48px 圆形；按钮 9999px；弹窗 16px 圆角 + 12px padding。动效：hover 叠加层 150ms，弹窗 scale 0.96→1 + 120ms fade，滚动中禁止打断动画。

## 记忆点与应用方式

复现"X 感"三步：①纯黑或纯白画布 + 零装饰；②信息流 600px 主列 + 275px 导航列；③胶囊按钮 + 小圆角卡片 16px，全站唯一彩色是 `#1D9BF0`。要表达"激进、快速、直给"就用黑底 ExtraBold 大字 + 蓝胶囊 CTA。

## 反混搭提示

X 是"彩色禁忌"最严格的社交场——不要把发帖/点赞/关注行为做成彩色渐变按钮，不要用卡片阴影堆叠层级，不要加玻璃拟态背景。巨大的渐变 hero 或插画风格会立即失去 X 品牌的"新闻性"与冷静感。
