# 反 AI 味小说写作

## 这个技能是什么

专门消灭"AI 腔"的小说写作技能。AI 腔的特征是顺滑、对称、爱下结论、句子成套。本技能反其道而行：让文字笨一点、具体一点、留白多一点。技法依据来自 30 部经典拆解（见 novels/），不是凭空定的审美偏好。

## 四条铁律

铁律违反即重写，没有例外。

### 1. 禁用破折号

正文与对话中一律不出现"——"。

破折号是解释欲的出口。它替读者把话说完，把节奏打断，是 AI 腔的头号标志。

- 删掉破折号，把后面的内容改成独立句，或直接删掉。
- 需要语气停顿，用句号，用逗号，或什么都不用。
- 需要补充说明，拆成两句话，或合并进前一句。

### 2. 禁用"不是……而是……"句式

这个句式是 AI 最爱用的升华句式，一出现就暴露套路。同类的还有"并非……而是""不仅仅……更是"。

- 改成直接写 B 本身。
- 不想直说，就写一个具体动作或场景，让读者自己悟。

### 3. 节制修辞

比喻、排比、举例三类修辞，全篇合计不超过三处，一处也嫌多时就不写。

- 比喻只留那个真正改变看法的，删掉装饰性的。
- 排比全部删掉。
- 举例只留一个最准的，其余都删。
- 修辞的功能是让陌生变具体，让抽象变可见，不是让普通变华丽。

### 4. 对话用动作或环境引出

不允许连续出现"某人说""某人道""某人开口"这种标签句。每个说话人必须带一个动作、一个细节或一处环境，读者从它识别说话人。

- 与其写"她把水桶换了只手，说"，不如写"她把水桶换了只手："，冒号后直接接话。
- 用动作、环境声、换行替代"说"字。
- 同一页"说/道"出现超过两次，说明引出方式太少，重写。

## 十三条写作法则

从 30 部经典拆解提炼的共性技法，每条都能在 novels/ 里找到范本。

1. 情绪不写词，写动作。《战争，我》里"她食指上缠的布条湿了"，胜过一百句"她哭了"。
2. 名字带信息。福贵、陈德厚、凉宫春日、伊莱莎，称呼本身就是人物。
3. 大事件小写，小事件大写。死亡一笔带过，一碗米汤写满一页，反差出力量。
4. 重复制造节奏。句子、场景、物件反复出现，意义在第三次出现时炸开。
5. 保留"不必要"的细节。三体的台球桌、沙丘的蒸馏服、边城的渡船，越无关越真实。
6. 短句与长句混用，长句只留给情绪最高点。
7. 一个视角走到底。第一人称或有限视角，读者只信一个人。
8. 时间结构用心经营。闭环、回忆、倒叙，先用结构定情绪再动笔。
9. 结尾留白，或收束到开头的物件。让最后一个画面停在读者脑子里。
10. 每个人说的话不一样。农民不论文言，少女不说官话，说话方式就是人物。
11. 悬念不放钩子，放事实。让读者比人物先知道一点，剩下的是煎熬。
12. 主题不点破。反战不必写"战争残酷"，写一截断掉的铅笔头就够了。
13. 如果是创作长篇小说，则每15章必须有个高潮(根据实际作品类型而定)，可以是戏剧性转折，也可以是其他的什么，总之非得要有一个(但是必须是有用的，所以每15章就要铺垫)；短篇小说根据实际。

## 拆解库使用协议

1. 打开 novels/index.md，按题材定位板块。
2. 选同一题材的拆解读两篇以上，只带走「反AI味借鉴点」里的写法。
3. 同一种写法换一个新场景，不复制原句。
4. 写完用下方清单自查，不过就改。

## 反 AI 味终检清单

写作或修改完成后逐条核对：

- [ ] 全文没有破折号
- [ ] 没有"不是……而是……"及同类升华句式
- [ ] 比喻、排比、举例合计不超过三处
- [ ] 每页"说/道"不超过两次，对话有动作或环境引导
- [ ] 没有"仿佛""好像"开头的装饰性比喻
- [ ] 没有一整段只讲道理
- [ ] 情绪处写的是动作或物件，不是情绪词
- [ ] 人名、地名、年代具体可查
- [ ] 结尾有画面，或回到开头的物件
- [ ] 通读一遍，删掉所有自认为"写得很妙"的句子
