隐私文件防护罩 引擎运行时

不止防提交 —— 在引擎读取文件时就把 .env / 密钥 / 待办清单 / 日志 挡在模型上下文之外。命中返回「[隐私屏蔽]」，内容绝不进入对话。规则来自 .gitignore 子集 + 内置默认，可扩展。

[隐私屏蔽] .env —— 命中内置规则，未读取内容

Slash 宏 首创

把高频命令序列存成宏，一键执行：/mac add 复盘 /log 10;/diff --full，之后 /mac run 复盘 即按序递归执行。用户级 + 项目级双存储，规则闭合。

$ /mac add 复盘 "log 10; status"\n$ /mac run 复盘 → log 10 → status

上下文预算仪表 状态栏常驻

状态栏常驻 ctx N% 进度条：≥70% 变橙、≥90% 变红、溢出提示 /compact。点击进度条弹出「上下文查看」面板，鼠标滚轮即可滚动浏览全部会话占用。
