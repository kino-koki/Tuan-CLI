## 文件命名与读取

- 每家公司独立文件：`companies/01-apple.md` … `companies/71-ikea.md`（编号 + 小写英文简称，见全表 # 列）。
- 原 30 家定本（01–29）为单文件完整规格：`## 设计规格` + `## CSS Token`；新增公司（30–71）内部分板块：软件公司为 `## HTML 板块 · 官网与营销页` 与 `## UI/UX 板块 · 产品界面`，实体品牌公司为 `## 官网板块 · 数字化品牌体验`。
- 只读取被选定一家的文件；禁止同时加载多家做混搭（见 SKILL.md 使用协议）。
- 各规格文件均含「核验说明」字段：数据为整理时快照，品牌规范可能更新，使用前建议核对官网。
