一、执行摘要

对青小团 v0.2.017 与 Kimi Code v2.1.1、Claude Code v2.1.283 进行了 15 个维度的逐维度对比，信源覆盖官方文档/changelog/GitHub + 第三方实测，每条结论标注可信度。

核心发现：青小团在模型中立性（51 provider）、插件架构（微内核）、多语言（10 语言）、开源（MIT）、价格（免费）、安全纵深等维度已领先或持平；在 Headless/CI 模式、代码编辑精度、自动记忆、交互效率 四个方面存在可补齐的差距。

三、逐项差距详析

差距1：Headless/CI 模式不够简洁 P0 已补齐

对标：Claude Code claude -p + --bare；Kimi Code kimi -p + --output-format stream-json
原状态：qxt run 输出混合 console.print 与 token stream，无结构化输出，无纯净模式，无 stdin 管道
补齐：-p/--print 纯文本流式 + stdin 管道；--output-format json NDJSON 五类事件；--bare 跳过用户配置/skills/hooks/MCP/记忆注入

差距2：代码编辑工具精度不足 P0 已补齐

对标：Claude Code Edit multi-cut + /diff 面板；Kimi Code v0.38.0 Read-before-Edit
原状态：edit_file 仅单次 str_replace，无 diff 预览，无 Read 守卫
补齐：multi-cut 多组替换（整体回滚）；Read-before-Edit 守卫（可配置关闭）；diff_preview 工具；edit 返回值附 unified diff 摘要

差距3：Auto Memory 自动记忆缺失 P1 已补齐

对标：Claude Code Auto Memory（user/feedback/project/reference 四类，自动写入）
原状态：MemoryStore 已有 FTS5/标签/时间索引，但记忆是被动的（需显式调用 memory_write）
补齐：规则启发式自动提取器（零 LLM 调用），Stop 事件后台触发，四类分类，去重，/memory 斜杠命令，memory.auto_extract 开关

差距4：交互效率工具不足 P2 已补齐

对标：Claude Code ! shell mode / TodoWrite / /init；Kimi Code kimi export
补齐：! 快捷 shell（复用安全护栏）；TodoWrite 持久化工具（落盘 .qxt/todo.json）；/init 项目引导生成 QXT.md；qxt session export zip 打包

差距5：IDE 扩展缺失 记录未实现

对标：Kimi Code VS Code 扩展+桌面端；Claude Code VS Code+JetBrains+Desktop
状态：青小团有 ACP 服务端可接 JetBrains/Zed，但无 VS Code 扩展、无桌面端
决策：工程量超出 CLI 项目范围（需独立 TS/JS 项目），ACP 协议已有接入点，留待后续迭代

差距6：云端功能缺失 架构性差距

对标：Claude Code Ultraplan/Routines/ultrareview/自托管云会话/remote-control；Kimi Code Remote Control
决策：青小团定位本地 CLI，不实现云端功能。cron + Web API 已覆盖本地自动化需求

四、已实现补齐详情

P0 Headless/CI 模式增强
对标 Claude Code -p/--bare 与 Kimi Code stream-json，让青小团真正可用于 CI/自动化管线。
  • qxt run -p "任务"：不进 TUI、不打印横幅/装饰，纯文本流式 stdout，错误走 stderr，退出码 0/1
  • cat file | qxt run -p：stdin 管道自动读取作为任务输入
  • --output-format json：NDJSON 每行一个事件（text/thinking/tool_call/tool_result/finish）
  • --bare：CI 纯净模式，跳过用户配置/skills/hooks/MCP/记忆注入，仅内置默认+内置工具
文件：cli/cmd_agents.py cli/parser.py app.py config/loader.py core/agent.py · 测试：test_headless_print.py (8项)
P0 代码编辑精度增强
对标 Claude Code Edit multi-cut + /diff 面板与 Kimi Code Read-before-Edit 守卫。
  • edit_file(path, replacements=[{old_string,new_string},...])：multi-cut 多组按序应用，任一组失败整体回滚
  • 旧的 edit_file(path, old_string, new_string) 单组方式完全向后兼容
  • Read-before-Edit 守卫（默认开启）：edit/覆盖式 write 前校验已 read_file，未读先改拦截提示
  • diff_preview 工具：unified_diff 预览不写盘；edit 返回值附 diff 摘要
  • 守卫可通过 tools.require_read_before_edit: false 关闭；新建文件不受限
文件：tools/filesystem.py tools/base.py · 测试：test_edit_multicut.py(4) test_read_before_edit.py(5) test_diff_preview.py(3)
P1 Auto Memory 自动记忆系统
对标 Claude Code Auto Memory，让 Agent 自动记住用户偏好、纠正、项目决策。
  • 规则启发式提取器（零额外 LLM 调用）：中英文关键词匹配，分类优先级 feedback > user > project > reference
  • 四类记忆：user(偏好) / feedback(纠正) / project(决策) / reference(事实链接)
  • Stop 事件后后台 daemon 线程触发，不阻塞主循环；异常全隔离
  • 写入前去重（归一化子串 + 3-gram Jaccard）；recall_context 按优先级注入
  • /memory list [kind] / /memory search / /memory add / /memory delete / /memory on|off
  • MemoryStore 新增 mkind 列（旧行默认 reference，ALTER TABLE 向后兼容）
文件：memory/auto_extractor.py(新增) memory/store.py core/agent.py cli/cmd_slash.py config/defaults.py · 测试：test_auto_memory.py(12项)
P2 交互效率工具四件套
对标 Claude Code ! shell mode / TodoWrite / /init 与 Kimi Code 会话导出。
  • !命令：REPL/TUI 输入 ! 前缀不经 LLM 直接执行 shell，复用 run_shell 全套安全护栏，输出自动注入下一轮上下文
  • todo_write 持久化：落盘 <workspace>/.qxt/todo.json，新增 todo_list，校验文案与既有 session_tools 一致
  • /init：扫描工作区识别语言/包管理器/测试框架/框架/目录结构，生成 QXT.md；已存在默认不覆盖，/init force 强制
  • qxt session export <id> -o out.zip：打包 session.jsonl + manifest + config快照(不含密钥) + 文件清单 + summary.md
文件：cli/cmd_bang.py(新增) tools/todo_tool.py(新增) cli/cmd_slash_init.py(新增) cli/cmd_session_export.py(新增) cli/cmd_chat.py cli/cmd_slash.py cli/cmd_session.py tools/__init__.py app.py · 测试：test_shell_bang.py(3) test_todo_tool.py(4) test_init_command.py(3) test_session_export.py(2)

六、青小团已领先/持平维度

  1. 模型中立性：51 provider，远超 Kimi Code(6类) 和 Claude Code(仅Claude) — 任何模型都能用
  2. 插件架构：微内核 + @plugin 装饰器 + 服务注册表 + 事件总线 + 拓扑激活，架构上优于配置式插件
  3. 多语言：10 语言 README + i18n 运行时翻译，领先双方
  4. 开源：MIT 开源，与 Kimi Code 并列，优于闭源的 Claude Code
  5. 价格：完全免费，优于双方订阅制
  6. 外部引擎架构：9 个 JSONL IPC 外部引擎（diff/json/safety/crypto/ansi/index/search/notify/rules），进程隔离，独特设计
  7. 安全纵深：security_bus + audit-export + CIDR 出口白名单 + 单向模式 + blast-radius 分析
  8. Hooks：8 种事件（PreToolUse/PostToolUse/UserPromptSubmit/Stop/SubagentStop/PreCompact/SessionStart/SessionEnd），与 Claude Code 持平
  9. MCP：完整支持 stdio + HTTP + 安全审计，与双方持平
  10. 子代理：SubAgentPool 并发隔离上下文，与 Kimi Code AgentSwarm / Claude Code Subagents 持平
  11. cron：内建定时任务，Kimi Code 无，Claude Code 靠 /loop + Routines
