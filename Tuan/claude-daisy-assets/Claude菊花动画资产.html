CLI Spinner
Claude Code
✶ Cogitating…

Claude Code CLI 的同款字符序列 ✶ ✻ ✽ ✢ · ✳ ∗ ✹ ✧，以 130ms/字符循环，模拟终端行内的「思考中」光标。

130ms/字符 · 9 字符循环 · JS 驱动
查看可复制代码 
<!-- HTML -->
<span class="term-spin" id="termSpin">✶</span>
<span class="term-verb">Cogitating…</span>

<!-- JS：Claude Code CLI 同款星号序列 -->
<script>
const SPIN=['✶','✻','✽','✢','·','✳','∗','✹','✧'];
let i=0,el=document.getElementById('termSpin');
if(el&&!matchMedia('(prefers-reduced-motion: reduce)').matches){
  setInterval(()=>{i=(i+1)%SPIN.length;el.textContent=SPIN[i];},130);
}
</script>

<!-- CSS -->
.term-spin{color:#D97757;display:inline-block}
.term-verb{color:#F5EDE3;animation:cd-breathe 2.6s ease-in-out infinite}

复用指南

三种接入方式，全部拷贝即用。

  1. 静态 logo：直接用独立文件 claude-daisy-symbol.svg，或复制下方「公共资源」里的 <path> 内联使用。
  2. 加载动画：从动画库里选一张卡片，点「查看可复制代码」，把对应 HTML + CSS 拷进项目；页面里同一份 <defs> 可被所有动画共用。
  3. 自定义：改 --terra / --cream / --cog 换色；改 animation-duration 调速；符号色统一由 use{fill:…} 控制。
性能
全部动效只用 transform / opacity，GPU 合成，不触发布局抖动。
无障碍
内置 prefers-reduced-motion：系统开启「减弱动态效果」时动画自动停用，静态菊花完整可见。
兼容
原生 CSS + SVG，无框架依赖；file:// 直开可用。
许可
符号路径 CC0 公有领域；动画代码自写可自由使用。使用「Claude」名称/符号时遵守 Anthropic 商标指引。
